# PhD Pilot · 功能说明与下载

PhD Pilot 是一个面向个人科研工作的 Windows 桌面工具，用于集中管理项目、资源入口、任务和手工进度。原始资料继续在 Obsidian、WPS、飞书或本地 Office 等来源中维护。

**当前版本：0.1.0-alpha.11.9 · Windows 11 x64 · Alpha 预发布**

[下载安装包](https://github.com/blackblues360/phd-pilot-downloads/releases/download/v0.1.0-alpha.11.9/PhD.Pilot_0.1.0-alpha.11.9_x64-setup.exe) · [版本说明](https://github.com/blackblues360/phd-pilot-downloads/releases/tag/v0.1.0-alpha.11.9) · [全部版本](https://github.com/blackblues360/phd-pilot-downloads/releases)

本仓库公开提供使用说明和安装包，不包含应用源码、内部设计文档、运行数据库或用户备份。无需登录 GitHub 即可查看和下载。

这份说明对应 **alpha11.9** 当前实现。资源支持「全部列表 / 原始目录 / 逻辑层级 / 关联网络」四种查看方式，默认保留完整列表；索引详情居中显示，可搜索任意其他索引建立或解除双向关联。已有功能、需要额外配置的连接，以及尚待真实账号验证的项目均在下文说明。

## 安装与升级

1. 下载 **PhD.Pilot_0.1.0-alpha.11.9_x64-setup.exe**。
2. 运行安装程序，按提示完成当前 Windows 用户的安装。本版面向 Windows 11 x64，使用 WebView2 Runtime。
3. 首次启动为空工作区，可先创建项目，再添加资料索引；在 Connections 中选择要连接的来源。

升级前请先在 Settings 导出 Pilot 备份并退出旧版，再安装新版。本版使用schema13，旧schema1–12首次启动先备份再升级，保留索引身份和关系；alpha11.8到11.9保持schema13。Pilot备份不包含外部文档、附件或网站登录状态，原稿需在原应用中另行备份。

应用仍在 Alpha 阶段，尚未进行 Windows 数字签名，也没有自动更新；后续版本从本仓库的 Releases 下载。

## 完整功能说明

### 1. 首页、全局看板与项目看板

- 首页可集中显示焦点项目、手工进度、实验进度、内部任务、已连接的只读日历日程、资料入口和最近操作。
- 全局看板汇总多个项目的入口；项目看板展示当前项目范围的数据。
- 通过 Current Project 或左下角选择器设置首页焦点项目；右上角的范围选择控制当前页面的项目过滤。这两个选择分别承担展示焦点与页面筛选作用。
- 资源卡片可以进入同一组资源的完整列表。飞书画板、组会与汇报也有专用入口卡片，用于打开已登记的链接。
- 首页显示天津当前天气和今日温度范围，定时及返回窗口时刷新；天气来源信息保留在设置中。

### 2. 看板布局与卡片管理

- 进入“编辑布局”后，通过手柄拖动卡片，通过右下角调整宽高，并保存布局。
- 可添加、隐藏、移除或恢复卡片；从看板移除卡片不会删除它所关联的任务、进度树或资源。
- 进度卡片可选择或更换绑定的进度树。项目卡片绑定本项目的树，全局看板可展示不同项目的树。
- 支持“补齐行间空白”，调整卡片之间的垂直留白；普通拖动保留用户安排的位置。
- 宽窄窗口的布局分别保存。未保存布局时会阻止相关切换，保存失败会保留草稿并提示。

### 3. 项目管理

- 新建项目，填写名称和目标，后续可以编辑。
- 项目卡片显示关联索引数量和手工进度树数量。
- 从项目卡片进入独立看板，或打开该项目的文档层级。
- 支持归档和恢复项目，保留其数据与关联。
- 同一条资料索引可以关联多个项目；按项目查看时仍使用原来的资源身份。

### 4. 内部任务与甘特视图

- 创建手工任务，设置标题、截止日期和所属项目，勾选完成或恢复未完成。
- 编辑任务，在同项目、同完成状态内调整顺序，或删除任务。
- Tasks 可切换“列表”“甘特图”“甘特图与列表”三种视图。
- 当前内部任务只有截止日期，因此甘特图显示截止节点；没有日期的任务仍保留在列表。
- 首页任务卡片与 Tasks 使用同一批内部任务。已连接的飞书日程在“全部项目”范围另行只读展示。

### 5. 多级手工进度树

- 为项目、论文或其他手工目标建立独立进度树，使用分组组织任务叶节点。
- 父分组按照所有任务叶节点等权汇总：例如两个阶段分别有 5 个和 3 个任务，总计 8 个，完成 2 个时总进度为 25%。
- 支持新建、重命名、移动、排序、添加同级或下级，以及删除普通进度树或节点。
- 支持快速连续添加节点，也可以粘贴或输入缩进大纲，一次建立整棵树或追加到指定分组。
- 大纲每行一个节点，Tab 或两个空格表示缩进；有下级的行成为分组，其余行成为任务。单次最多 500 个节点、32 层相对深度。
- Tasks 的完成状态、外部文档状态和日历事件不会自动改变进度树的完成率。

### 6. 实验进度与历史

- “新建实验进度”会创建独立实验树，可手动维护“未开始”“等待中”“已结束”状态。
- 首页实验卡片显示当前实验与进度；已结束的实验从首页活动列表隐藏，但仍可在 Progress 查看历史。
- 可以将已结束实验重新设为其他状态，继续维护。
- 实验根与节点保留，不支持删除或跨实验搬移。
- Experiments 页面管理的是“实验方案”资料索引；实验执行进度在 Progress 中维护，两者可以配合使用。

### 7. 统一资源索引与分类页面

- Resources 保存全部资源索引；Experiments、Literature、Libraries、Ideas 和 Documents 展示其中符合条件的同一条资源。
- 例如，一份 Obsidian 实验方案可同时出现在 Resources、Experiments 和 Documents → Obsidian 中，索引 ID、别名、标签和关联保持一致。
- 支持登记普通 HTTPS 地址和已有本地文件；索引可以有标题、Pilot 别名、标签、备注、资源类型和项目关联。
- 支持将相关资源相互关联，也可以关联已有实验方案；这些关系与进度树、文档 Parent 和 SOP 版本绑定分别管理。
- 索引详情可查看已缓存的信息、编辑允许的 Pilot 字段，选择网页打开偏好，或移除索引。移除索引不会删除原始文件或云文档。
- Resources提供四种并列视图：默认全部列表保留原组合筛选与列宽；原始目录按缓存文件夹／集合展开；逻辑层级可创建项目下的阶段、实验和分组，任一资源可归属多个节点；关联网络默认显示直接关联，可展开第二层。
- 任一索引详情均居中显示，可搜索全库其他索引建立双向关联，支持跨来源、类型和项目；防止重复及自关联，双方均可导航和解除。解除关系或删除逻辑分支只影响Pilot内部记录。
- 关系图仅使用已保存的关系，不解析正文双链或通过同目录自动推断。Zotero同一文献可在多个集合中显示，仍共用一个资源ID；飞书／WPS尚无目录元数据时使用手工链接分组。
- 普通本地文件由系统默认应用打开；网页可在 Pilot 中打开，也可明确选择系统浏览器。

### 8. 搜索、筛选与表格操作

- 顶部搜索可查找已登记资源的标题、别名、标签、备注、类型、来源及索引 ID，并查找项目名称与目标。
- 索引表头支持组合筛选类型、来源、关联项目和可用性；无结果时可以清除筛选。
- 支持在不同用途页、文档来源页及连接目录的成员列表中使用同一套索引表格。
- 可拖动列边缘调整列宽，也可聚焦边缘按钮后使用左右方向键调整；列宽可保存。
- 搜索与筛选针对 Pilot 已缓存的元数据，不执行外部文档全文搜索。

### 9. 本地文件属性与移动后的认领

- 登记本地文件后保存必要的文件属性和 Windows 文件身份，详情中可手动刷新。
- 文件失联、无法访问或刷新失败时保留原索引、关联和上次成功信息。
- 文件移动后，可通过“重新选择并认领”授权新位置，或在已授权目录刷新时核对身份。
- 身份明确匹配时保留原资源 ID、标签和项目关联；不会仅凭同名文件自动合并。
- 认领核对的是文件身份与属性，不代表对文件正文进行一致性或内容校验。

### 10. 文档、正式版本与具体文件

- Documents 默认按“全部 / Obsidian / WPS / 飞书”等来源显示已有文档索引，无需先把普通资源转换成另一份索引。
- “文档身份与版本”管理逻辑文档、正式版本和具体文件表现之间的关系。
- 同一逻辑文档可关联工作稿、正式版本及其他格式文件；文档 UUID、版本 UUID 与 Pilot 资源 ID 分别管理。
- 支持选择或粘贴用户确认的纯元数据 JSON，先预览校验、选择对应的已登记资源，再确认整批导入。
- 元数据清单使用 phd-pilot-metadata/v1 格式，可表达来源已有的 doc_id、record_kind、type、version_id、version、Parent 和获准扩展元数据；正式版本必须使用来源已有的版本身份。
- 身份冲突会提示并阻止不一致导入；修改清单或相关数据后需要重新预览。
- 解除文件映射可保留资源与文档、版本身份；移除资源索引也不会自动删除既有版本或 SOP 绑定。

### 11. 文档层级、项目继承与 SOP 引用

- 为文档选择已有上级，清除上级，或恢复从来源元数据导入的 Parent；这些手动调整保存在 Pilot 内。
- 项目规划文档满足条件时可绑定项目根，其后代沿文档层级继承项目归属。
- 支持项目文档树、展开与收起，以及保留上级上下文的层级搜索。
- 手工项目关联与层级继承分别保留；解除手工关联不会抹除仍有效的继承关系。
- 实验记录可以绑定 SOP 的某个具体正式版本；后续新增 SOP 版本不会把旧记录自动改绑到最新版。
- SOP 文件不可用时仍保留版本身份并显示状态。当前不在 Pilot 中直接发布或生成来源侧的 SOP 快照。

### 12. 本地资料目录连接

- 在 Connections 通过系统选择器指定目录，选择来源、默认类型和可选项目，然后建立索引。
- 可以只选择勾选的子文件夹，每个范围分别连接、暂停与刷新；支持取消进行中的扫描。
- 当前索引扩展名包括 .md、.docx、.xlsx、.pptx、.pdf、.txt、.csv。
- 跳过隐藏、插件、附件和缓存目录，以及符号链接、Windows 目录联接；不递归扩展到用户未选择的范围。
- 首次连接扫描，之后由用户主动刷新。重复扫描复用已登记条目，并保留手工别名、标签和关联。
- 完整扫描后才将未见文件标记为失联；部分失败时保留未见条目的缓存。暂停连接不删除资源。
- 手工移除的条目会记录排除，可明确重新纳入；刷新不会自动撤销用户的移除决定。

### 13. Obsidian 手动元数据同步

- 用户自行打开目标 Vault 并启用 Obsidian CLI，再在 Connections 中选择范围、执行核验或同步。
- “只读核验已有身份”返回候选报告；“同步身份及位置”重新核验后保存 Pilot 的来源映射。
- 当前只读取获准的六个字段：doc_id、source_entry_id、version_id、record_kind、type、version，以及必要文件属性。
- 支持 UUID 身份复用、授权范围内改名或移动后重定位、重复身份与冲突报告；失败保留已有缓存。
- 来源已核验的类型用于分类，未知类型保留原值，不强制改写成预设类型。
- Obsidian 连接为手动操作，没有后台持续同步；不会修改 Markdown 正文、写回 YAML、补写 UUID 或替用户安装插件。

### 14. WPS、飞书网页与 Zotero

- 个人 WPS：打开官方云文档入口，用自己的账号登录，登记原页面地址，或在已打开页面旁选择“保存到 Pilot”。
- 新保存的准确 WPS 云文档主机会归入 WPS 来源；保存地址本身不调用创建分享链接或修改权限。
- 桌面 WPS：在云文档文件菜单选择“用 WPS Office 打开”，再在 Pilot 确认；关闭确认框即取消，页面跳转后旧请求失效。
- 飞书文档、飞书画板、组会与汇报等已有资源可手工登记并作为导航入口；WPS／飞书云目录API尚未接入。
- Zotero：在Zotero启用Local API后，Connections → Zotero选择个人文献库集合，主动同步勾选集合的书目元数据。子集合需单独勾选；支持已同步集合的直接文献列表，原始目录树保留集合层级和多集合成员关系。失败保留索引，不后台自动同步。
- 文献详情分别提供「用WPS打开本地PDF」「在Zotero定位条目」「在Pilot打开原始网页／DOI」入口；需本机已安装对应软件及附件已下载。不读取摘要、笔记或PDF正文，不回写Zotero。

### 15. 飞书日历只读展示

- 通过启动应用进程的 CalDAV 配置读取日程，在首页任务卡片、Tasks 列表和甘特图中展示。
- 自动读取范围为上海日期过去 7 天至未来 90 天；启动、窗口可见期间每 5 分钟、返回窗口时检查更新，也可手动同步。
- 自动请求至少间隔 1 分钟，同一时刻不并发；页面切换保留本次会话的结果。
- 失败保留上次成功日程，成功空结果清除旧日程；显示连接提示和上次成功时间。
- 云端日程只在“全部项目”显示，不自动关联项目，不能在 Pilot 中编辑、删除或勾选完成。
- 当前使用 CALDAV_URL、CALDAV_USERNAME、CALDAV_PASSWORD 环境配置，没有应用内账号输入和凭据保存界面；从快捷方式启动是否继承配置需要自行核验。
- 日历与飞书「我的任务」使用独立连接：在Tasks完成官方用户授权后可只读同步自己的任务，日历条数不代表任务条数；任务标题通过飞书客户端打开。飞书任务和日程均不写入内部任务数据库／备份，不能勾选完成或回写来源；已完成飞书任务默认折叠。

### 16. 内置浏览器

**网页与页签**

- 地址输入、搜索、前进后退、刷新停止、页内查找，支持 50%–200% 缩放。
- Bing、百度、PubMed、Google、DuckDuckGo 五种搜索引擎可选，选择可保存。
- 最多 30 个页签，支持拖动排序、键盘排序及溢出滚动；重启后按会话恢复选中页面。
- 已加载网页切换时保留缓冲；可手动休眠页面，休眠前提示未保存编辑可能丢失。
- 用户触发的新窗口链接打开为新 Pilot 页签；需要登录回传的站点可先在“更多”允许一次受控登录弹窗。
- 普通在线 PDF 可使用 WebView2 阅读器查看。

**常用网站与保存索引**

- 新标签页可添加、编辑、移除和排序常用网站卡片，最多 32 个；名称、HTTPS 地址和顺序可保存，并随 Pilot 备份恢复。
- 常用网站卡片是快捷入口，不会自动生成资源索引。
- “保存到 Pilot”先预览标题与地址，可填写 Pilot 备注，关联项目、实验方案和其他资源，再确认保存。
- 重复位置复用原索引，保留既有身份及手工信息；页面跳转后需要重新预览。
- 网页资源可明确选择系统浏览器，也可保存资源或站点的外部打开偏好。

**登录与权限**

- Pilot 使用独立网站会话，不导入其他浏览器的登录状态。
- 支持同一 Windows 用户及本机数据目录内的加密登录检查点；网站主动过期或撤销后仍需重新登录。
- 网站请求相机、麦克风、位置、通知、剪贴板或连续下载权限时，可按网站与类型选择允许或拒绝，并管理已记录规则。
- 飞书和受支持的 WPS 客户端跳转需要确认；其他客户端协议可能被阻止。
- 网页内容区固定浅色；全局深色主题不会自动把网页变暗。

**下载与清理**

- 普通文档、数据表和图片可下载到默认下载目录的 PhD Pilot 文件夹，也可询问保存位置；同名文件不覆盖。
- 可查看下载进度、取消、打开完成文件、显示文件位置，并选择把完成的文件添加为索引。
- 应用内下载限制可执行、宏和快捷方式等文件类型；下载安装本软件请使用系统浏览器中的本仓库下载链接。
- 下载记录主要用于当前会话；已下载文件不会因为清空记录而被删除。
- 点击下载卡片外部会关闭卡片，内部操作保持；关闭不取消正在下载的任务或删除记录。
- 可分别清理缓存、登录数据、历史/恢复描述、下载记录和下次恢复页签；清理缓存与清理登录数据是不同操作。

### 17. 外观、封面与资源类型

- 五种全局主题：Sage、Blue Gray、Sand、Rose、星云。
- 看板右侧封面支持 JPEG、PNG、WebP，原文件不超过 15MB；可恢复默认远山，封面在本机处理和保存。
- Settings 可统一管理当前看板的卡片，并查看应用版本、数据目录与数据库结构版本。
- 可查看预设、自定义和已缓存来源类型，新增手工资源类型用于登记与筛选。
- 预设类型包括项目规划、阶段方案、实验方案、实验记录、SOP、技术方法、调研、汇报、手册、飞书画板、组会记录、文献、网页、样本/细胞库、试剂/库存、想法、实验结果。
- 这些名称用于资料分类，其中“样本/细胞库”“试剂/库存”不代表已经实现完整库存或样本业务系统。

### 18. 备份、恢复与近期删除

- 在 Settings 通过系统选择器导出 .pilotbackup 文件，同名文件不会直接覆盖。
- 恢复前预览备份时间、版本与当前/备份数据数量，明确确认后再执行；相关数据变化后需重新预览。
- 恢复前自动保留当前状态的恢复点；恢复失败时尝试回滚，并提供后续处理提示。
- 普通任务、普通进度树及节点的近期删除可在 10 分钟内撤销；存在后续冲突时会阻止覆盖，实验记录仍遵守保留规则。
- 恢复全库备份会回到备份保存的状态，可能回退之后的新数据；不能把应用内“保留记录”理解为全库恢复永不回退。

## 第一次使用的建议流程

1. **创建项目**：通过 New → 新建项目，填写名称和目标。
2. **登记资料**：手工添加已有文档地址或文件；资料较多时到 Connections 选择目录及范围。
3. **建立关联**：给资料添加项目、类型、标签和备注；需要正式文档身份时再使用元数据导入或 Obsidian 手动同步。
4. **安排工作**：Tasks 记录要完成的事项；Progress 建立需要持续统计完成率的进度树。
5. **记录实验进度**：为每个实验建立进度树并维护状态，把实验方案、SOP 和结果资料作为索引关联起来。
6. **整理看板**：按自己的使用习惯调整卡片和封面，保存布局。
7. **定期导出备份**：在升级或较大调整前保存 Pilot 备份，原始资料在来源应用中另行备份。

New 创建的是 Pilot 内部对象或索引，不会替用户在云端创建文档或向 Obsidian 写入新笔记。

## 数据保存与备份范围

Pilot 的业务数据在使用者本机 SQLite 中保存，实际位置可在 Settings 查看。索引器读取获准元数据；用户在网页中主动浏览、编辑或下载，不会扩大索引器的读取权限。

| 数据 | 是否包含在 Pilot 备份中 |
|---|---|
| 项目、内部任务、进度树、实验状态 | 包含 |
| 资源索引、标签、备注、互联、逻辑节点／归属、Zotero元数据和文档身份映射 | 包含 |
| 文档层级、项目继承与 SOP 版本绑定 | 包含 |
| 看板布局、主题、自定义封面、资源类型及常用网站 | 包含 |
| 原始文档、科研正文、附件和下载文件 | 不包含，需另行备份 |
| 浏览器 Cookie、登录检查点、缓存、历史及页签恢复文件 | 不包含 |
| 飞书任务／日历会话结果、连接凭据及本机程序选择 | 不包含 |

备份文件本身没有加密，也没有定时云上传；请保管好包含个人索引和关系信息的备份。来源文件在新机器上的路径可能不同，恢复Pilot后仍可能需要刷新或重新授权位置。当前直接恢复只接受schema13备份；旧版备份需使用匹配旧版恢复后再按既有流程升级。

## 当前限制与常见问题

**这是完整的文档编辑器吗？** 目前用于项目组织、元数据索引、导航和手工进度。正文继续在原应用或网页编辑器中维护，Pilot 没有提供 Office 格式转换、全文 AI 分析或完整知识图谱。

**登记网页地址会自动开启分享吗？** 登记本身不创建分享链接或修改权限。云文档仍受原账号权限约束；若站点要求转换协作模式，应先停止并单独确认该类型的打开方式。

**能直接一键进入桌面 WPS 吗？** 当前先到云文档文件菜单选择“用 WPS Office 打开”，再由 Pilot 确认。索引点击一步直达客户端尚未实现。真实账号、文档类型和客户端版本仍可能影响兼容性。

**重新启动后所有网站都会保持登录吗？** 登录检查点仅适用于同一 Windows 用户和本机数据目录。网站过期、注销、部分站点会话机制、强杀或断电可能使登录丢失；清理登录数据后需重新登录。

**有资源类型就能使用对应的云服务吗？** 类型和来源分类用于整理已登记的入口，不代表已接通该平台的目录接口。请参考上面的来源能力表。

**天气可以选择任意城市吗？** 当前固定展示天津，尚未提供城市切换界面。

**是否支持多人同步或多设备自动同步？** 当前以本地个人工作区为主，没有 Pilot 业务数据的多人实时协作或自动云同步。外部站点自己的协作功能由站点管理。

**是否所有功能都完成真实环境验收？** 产品功能已有本地构建、单元检查和隔离桌面验证。安装版真实 WPS/飞书/Google 账号兼容、日历配置继承、跨重启、多物理 DPI、部分设备权限及干净系统安装/卸载仍需实际环境验收，不将测试替身当成真实账号结果。

**安装时为何可能显示未知发布者？** 当前安装包尚未进行 Windows 数字签名，没有自动更新服务。可先核对下方 SHA-256，并从本仓库的正式下载链接获取。
